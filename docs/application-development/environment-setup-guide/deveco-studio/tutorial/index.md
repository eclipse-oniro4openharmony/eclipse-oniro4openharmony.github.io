# DevEco Studio In-Depth Tutorial

The previous pages covered downloading, installing, and configuring **DevEco Studio**. This tutorial goes further and walks through the day-to-day workflows you will use while actually building an OpenHarmony/Oniro application: navigating the IDE, understanding a project's layout, using the Previewer and emulator, debugging and profiling, signing a build, and working with version control.

!!! info "Before you start"
    This tutorial assumes DevEco Studio is already installed and configured, and that the OpenHarmony SDK, Node.js and Ohpm have been set up as described in [Environment Configuration](../env-config.md). If that is not the case yet, complete that page first.

## What you will learn

| Page | Topic |
|------|-------|
| [Interface Tour](interface-tour.md) | The main window, tool windows, and essential keyboard shortcuts |
| [Project Structure](project-structure.md) | What each generated file and folder is for, Stage vs FA model |
| [Editor Features](editor-features.md) | Code completion, refactoring, navigation, and inspections for ArkTS/ArkUI |
| [Using the Previewer](previewer.md) | Real-time preview, multi-device preview, and interactive preview |
| [Emulators and Devices](emulators-and-devices.md) | Creating emulators with Device Manager and connecting real hardware |
| [Debugging and Profiling](debugging-and-profiling.md) | Breakpoints, HiLog, and the CPU/Memory/Network profilers |
| [Build Variants and Signing](build-and-signing.md) | Debug vs release builds, automatic and manual signing, packaging |
| [Version Control](version-control.md) | Built-in Git integration and recommended `.gitignore` rules |

Each page is self-contained, but they are ordered so that later pages assume familiarity with the ones before them. Feel free to jump directly to the topic you need.
