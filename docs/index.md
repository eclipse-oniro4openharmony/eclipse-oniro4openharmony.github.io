## About Oniro

[Oniro](https://oniroproject.org/) is an open-source, vendor-neutral operating system (OS) managed by the [Eclipse Foundation](https://www.eclipse.org/). It builds on [OpenHarmony](https://gitcode.com/openharmony/docs), an open-source project incubated and operated by the [OpenAtom Foundation](https://www.openatom.org/). OpenHarmony provides distributed-OS features for smart devices of many sizes. Oniro extends the OpenHarmony codebase with additions for European and global markets, including [React Native](https://reactnative.dev/) support, an [Eclipse Theia](https://theia-ide.org/)-based IDE, and the [Servo](https://servo.org/) web engine.

## The Project

The [Oniro Project](https://projects.eclipse.org/projects/oniro) was established through an agreement between two major global open-source foundations: the Eclipse Foundation and the OpenAtom Foundation. The collaboration aims to advance the development and global adoption of OpenHarmony. As an Eclipse Foundation project and [Working Group](https://www.eclipse.org/org/workinggroups/oniro-charter.php), Oniro benefits from the foundation's experience in open-source governance. This structure promotes transparency and active community participation.

The project includes enhancements to application frameworks, system-level OS components, and integrated development environments (IDEs). It also includes an advanced toolchain for compliance with intellectual-property and licensing standards. Oniro emphasizes interoperability, modularity, and an intuitive user interface. The platform supports technologies and applications across sectors such as consumer electronics, home appliances, industrial IoT, smart homes, and multimedia.

Learn more on the [Oniro Project website](https://oniroproject.org).

## The Code

Oniro code is hosted in the [Eclipse Oniro for OpenHarmony](https://github.com/eclipse-oniro4openharmony) organization on GitHub. The project also mirrors repositories from the [OpenHarmony organization on GitCode](https://gitcode.com/openharmony) to the [Eclipse Oniro Mirrors organization on GitHub](https://github.com/eclipse-oniro-mirrors). The Eclipse Oniro build system consumes these read-only mirrors. Mirroring improves access speed and reliability and simplifies forking on GitHub. A CI workflow synchronizes the mirrors every 24 hours.


## Quick Start

To start working with the code and building Oniro, follow the [build tutorial](device-development/building-oniro.md). To try Oniro on physical hardware, consider the HiHope HH-SCDAYU200 development kit, which uses Rockchip's RK3568 processor and is available in Europe and the United States.
