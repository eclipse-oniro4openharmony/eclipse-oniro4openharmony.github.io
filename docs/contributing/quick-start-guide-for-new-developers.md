This page provides a **quick-start contribution guide** for new developers
who want to join the Oniro Project.

## Setting Up

### Creating an Eclipse Account

Head to the [Eclipse foundation
website](https://accounts.eclipse.org/user/register?destination=user/login)
and set up an account by entering your:

- Email
- Username
- Full name
- Organization
- Password
- Country

Read the Terms of Use, Privacy Policy, and Code of Conduct, then select the
checkbox to accept them. Follow the instructions sent to
your email to activate the account.

### Signing the ECA

To contribute to the project, sign the [Eclipse Contributor
Agreement](https://accounts.eclipse.org/user/eca), which describes the
terms under which you can contribute to the project.

If you sign this ECA, you confirm your legal rights to submit the code
to the project. You also grant Eclipse and specified users a license to your
contributions; however, you retain ownership of them.

### GitHub Account

You can use a regular GitHub account to contribute to Oniro. If you do not
have one already, head to [GitHub](https://github.com/) and create one.
